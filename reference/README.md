# Sapir Developer Hub · интерактивный UI-прототип

**Назначение:** показать разработчикам, каким должен стать первый интерфейс Sapir Developer Hub. Этот прототип можно открыть в браузере без установки зависимостей.

## Как открыть

1. Распакуйте архив.
2. Откройте `index.html` в Chrome / Edge.
3. Закройте полноэкранное приветствие кнопкой или Escape. Кнопка со звездой в верхней панели показывает приветствие повторно.
4. Потяните сапфир на экране «Обзор», чтобы повернуть его. Откройте раздел через панель или Ctrl+K. Для перемещения панели удерживайте рукоятку с точками и потяните к краю окна. Позиция сохраняется в текущем браузере.
5. В графе знаний перетащите узел. «Сбросить» возвращает исходную раскладку, клик по узлу открывает документ.

Если браузер ограничивает доступ к буферу обмена для `file://`, запустите локальный сервер в этой папке:

```bash
python -m http.server 8080
```

Затем откройте `http://127.0.0.1:8080/`.

## Важный статус

- **Это только прототип интерфейса** на HTML, CSS и JavaScript.
- Все задачи, документы, сообщения, статусы интеграций, версии и пути проектов — **демонстрационные данные**.
- Кнопки установки `AGENTS.md` показывают демо-изменения в памяти страницы и **не записывают файлы на диск**.
- Нет вызовов ClickUp, Outline, Slack, GitHub, Tauri или AI API.
- Нет отдельных аккаунтов, авторизации или сохранения токенов.
- Реальное приложение предполагается на **Tauri 2 + React + TypeScript + SQLite FTS5**, а этот прототип — визуальный и функциональный референс.

## Файлы

- `index.html` — оболочка интерфейса, нижняя панель, приветствие и иконки SVG.
- `styles.css` — дизайн-система, расположение экранов и адаптация.
- `app.js` — переходы, сценарии и mock data.
- `brand.css`, `motion.js`, `prism.js`, `assets/` — анимированные слои, физика графа, интерактивная сцена сапфира и фирменные логотипы.
- `UI_SPEC.md` — подробное ТЗ на экраны, данные и интеграции.
